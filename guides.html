🏁 游戏概述

流放之路2（Path of Exile 2）是 Grinding Gear Games 开发的暗黑风格 ARPG。继承一代深度复杂的养成系统，采用全新引擎重制，带来更流畅的战斗体验和更精美的画面表现。

开发商Grinding Gear Games
国服代理腾讯游戏
平台PC / PS5 / Xbox Series X|S
核心玩法剧情推进 → 终局地图 → 赛季联赛
💡 POE2采用免费游玩模式，所有游戏内容均可免费体验，仅外观道具收费

章节概览

Act 1 · 暗影海岸

河岸 → 皆伐营地 → 皆伐 → 神秘营地 → 不朽帝国之墓 → 猎场 → 奥格姆宅第

关键节点：13 个 · 凛冬狼头颅、奥格姆典籍等永久奖励

Act 2 · 瓦斯提里沙漠

瓦斯提里郊区 → 阿杜拉车队 → 凯斯城 → 泰坦之谷 → 戴斯哈 → 无畏队

关键节点：22 个 · 升华试炼 1、深渊工作台

Act 3 · 兩生神域

风沙沼泽 → 高地神塔 → 丛林遗迹 → 吉卡尼的机械迷城 → 玛特兰水道 → 淹没之城 → 漆黑密室

关键节点：18 个 · 升华试炼 2、重铸台

Act 4 · 海岛探索

金司马区 → 金氏岛 → 悉妮蔻拉之眼 → 废弃监狱 → 伯劳鸟之岛 → 阿拉塔斯 → 部族之心

关键节点：17 个 · 永久天赋、抗性奖励

Act 5 · 黑曜要塞 0.5 新增

林间空地 → 群山小径 → 黑曜要塞主线区域

关键节点：22 个 · 0.5 赛季新增剧情，含赛季奖励标记
