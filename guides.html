🏁 游戏概述

流放之路2（Path of Exile 2）是 Grinding Gear Games 开发的暗黑风格 ARPG。继承一代深度复杂的养成系统，采用全新引擎重制，带来更流畅的战斗体验和更精美的画面表现。

开发商Grinding Gear Games
国服代理腾讯游戏
平台PC / PS5 / Xbox Series X|S
核心玩法剧情推进 → 终局地图 → 赛季联赛
💡 POE2采用免费游玩模式，所有游戏内容均可免费体验，仅外观道具收费

章节概览

Act 1 - 奥格姆地区

初始海岸 → 皆伐营地 → 葛瑞爾林 → 纏縛陰林 → 不朽帝国之墓 → 獵場 → 奥格姆宅第

关键奖励: +10%冰冷抗性、+2天赋、+30精魂、+20最大生命、解锁分解台

Act 2 - 瓦爾克拉斯沙漠

瓦斯提里郊區 → 阿杜拉車隊 → 凯斯城 → 泰坦之谷 → 戴斯哈 → 無畏隊

关键奖励: 升华试炼1、+4天赋、+10%闪电抗性、解锁深渊工作台

Act 3 - 瓦爾文明遺跡

風沙沼澤 → 高地神塔 → 叢林遺跡 → 吉卡尼的機械迷城 → 瑪特蘭水道 → 淹没之城 → 漆黑密室

关键奖励: 升华试炼2、+4天赋、+30精魂、+10%火焰抗性、解锁重铸台

Act 4 - 海岛探索

金司馬區 → 金氏島 → 悉妮蔻拉之眼 → 廢棄監獄 → 伯勞鳥之島 → 阿拉塔斯 → 部族之心

关键奖励: +6天赋、+5%最大魔力、+5%抗性×3、药水buff
💡 提示：剧情中有多个永久奖励（天赋书、抗性、精魂等），建议每个都拿到，对后期发育很有帮助
