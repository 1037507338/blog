前言

老孤独 0.5 版本国际服首发用武圣开荒起手。

优点是打击感极强，缺点是打 BOSS 时 GGG 喜欢连招，武僧开荒有一定难度。冰川之刺转浪涌奔雷鸣最舒服，不需要太多猴戏，按键可以相对少点。

💡 核心思路

第一章用 冰川之刺 过渡，第二章 22 级拿到 3 个 7 级技能石后转 移风岚 + 霹雳闪 引爆体系，一路推到异界。

⚠ 注意

第一章技能千万别拿错，前期技能拿错了会大幅降低效率。

第二章 · 浪涌奔雷鸣成形

22 级之前

22 级以后（需要 3 个 7 级技能石）

⚔ BOSS 循环输出手法

移风岚 上感电 → 汲能击 消耗感电获取暴击球 → 冰凌座 取消后摇 → 霹雳闪 消耗暴击球打爆冰凌座高额伤害 → 大概率再挂感电循环

第四章 · 跑图与装备

跑图优先级

⚠ 跑图顺序

先跑能拿到冰火电 5 点抗性 + 2 天赋点的两个图，再跑别的。

监狱放最后打，怪恶心 + 潮水机制。

装备选择

部位核心词缀备注
武器1-12 级细杖13 级后空手，45 级后有好词缀武器可替换
防具高闪避 / 闪避护甲底子剧情用闪避底子，异界换闪避+护盾底子
鞋子移动速度优先次选生命+抗性
手套攻击附加伤害 + 近战等级次选生命+抗性
腰带高血量抗性—
戒指攻击附加伤害其次生命抗性
项链生命抗性优先有近战等级更好

升华选择
